# NDT Inspector

Downloads for NDT Inspector, a Windows app for checking ultrasonic wall
thickness data from riser joints before it goes into a report.

## Download

[NDT-Inspector-Setup.exe](https://github.com/diabdimash/ndt-inspector-releases/releases/latest/download/NDT-Inspector-Setup.exe)
(always the newest version)

Older versions are on the [Releases](https://github.com/diabdimash/ndt-inspector-releases/releases) page.

## Installing

Run the downloaded file. No admin rights are needed.

Windows SmartScreen may say "Windows protected your PC". Click More info,
then Run anyway.

The app shows up in the Start menu. It can be removed from Settings > Apps;
your sessions and settings are kept.

## Updates

When a new version is out the app tells you. Click Install & restart and it
updates itself, no need to download anything again.

## Getting started

The first time it opens you can load a sample session or take the guided
tour. Both are also under Settings > Help & about.

## Requirements

Windows 10 or 11, 64-bit.
